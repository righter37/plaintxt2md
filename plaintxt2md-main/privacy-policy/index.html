🔒 隐私政策

AI Text to Markdown Converter | 最后更新日期：2024年3月

简要说明：本扩展高度重视用户隐私。所有数据处理均在本地完成，API Key 仅保存在您的浏览器中，不会上传到任何第三方服务器。

1. 数据收集

本扩展不收集任何个人数据。具体来说：

  • 不会收集您的浏览历史
  • 不会收集您的个人信息
  • 不会追踪您的使用习惯
  • 不会上传您转换的文本内容

2. 数据存储

仅在您的浏览器本地存储以下信息：

2.1 API Key

您提供的 DashScope API Key 使用 Chrome 的 storage.local API 存储在浏览器本地。这意味着：

  • ✅ 仅保存在您的设备上
  • ✅ 不会上传到我们的服务器
  • ✅ 不会与第三方共享
  • ✅ 卸载扩展后自动删除

2.2 用户设置

您的偏好设置（如选择的 AI 模型、输出风格）同样存储在本地浏览器中。

3. 权限说明

本扩展请求的权限仅用于实现核心功能：

storage

用途：保存您的 API Key 和设置

activeTab

用途：获取当前页面中选中的文字

contextMenus

用途：在右键菜单中添加「转换为 Markdown」选项

sidePanel

用途：启用 Chrome 侧边栏功能

https://dashscope.aliyuncs.com/*

用途：连接到阿里云 DashScope API 进行 AI 转换

4. 第三方服务

当您使用 AI 转换功能时，文本会发送到：

  • 阿里云 DashScope - 用于大模型文本分析

请同时查阅 阿里云隐私政策。

本地转换功能不连接任何外部服务。

5. 数据安全

我们采取以下措施保护您的数据：

  • 所有本地数据存储使用浏览器原生加密存储
  • API 调用使用 HTTPS 加密传输
  • 代码开源，可审查（GitHub 链接）

6. 用户权利

您拥有以下权利：

  • 访问权：随时查看或修改存储的设置
  • 删除权：卸载扩展即可删除所有本地数据
  • 选择权：可选择使用本地模式，不发送任何数据到云端

7. 儿童隐私

本扩展不面向13岁以下儿童。如果您是父母或监护人，发现儿童在使用本扩展，请联系我们。

8. 政策更新

我们可能会不时更新本隐私政策。如有重大变更，我们会通过扩展更新说明或 Chrome Web Store 页面通知您。

9. 开源声明

本扩展是开源项目，源代码可在 GitHub 上查看。欢迎审查代码以确保隐私安全。
